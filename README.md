# R Bio Data Analysis 🧬🌱

## 📌 Overview

This repository contains a collection of biological data analysis projects performed using R. The projects demonstrate the application of R programming, data analysis, visualization, and bioinformatics techniques to biological datasets.

## 📂 Projects

### 1. 🌱 Plant Growth Analysis

This project analyzes plant growth data using R to identify patterns and differences in plant growth under different experimental conditions.

**Techniques used:**
- Data cleaning and organization
- Descriptive statistics
- Data analysis
- Data visualization
- Biological data interpretation

---

### 2. 🧬 BRCA1 Sequence Analysis

This project focuses on computational analysis of the **BRCA1 (Breast Cancer 1)** gene using R and Bioconductor.

The analysis includes nucleotide sequence processing, subsequence extraction, reverse complement generation, genomic coordinate analysis, and gene annotation.

**Techniques and tools used:**
- R
- Bioconductor
- Biostrings
- GenomicRanges
- AnnotationDbi
- FASTA sequence analysis

**Key information:**
- Gene: BRCA1
- Entrez Gene ID: 672
- Chromosome: 17
- Sequence length analyzed: 7088 bp

---

### 3. 🧬 EGFR Sequence Analysis

This project focuses on computational analysis of the **EGFR (Epidermal Growth Factor Receptor)** gene using R and Bioconductor.

The analysis includes nucleotide sequence analysis, genomic coordinate representation, strand identification, and gene annotation.

**Techniques and tools used:**
- R
- Bioconductor
- Biostrings
- GenomicRanges
- AnnotationDbi
- FASTA sequence analysis

**Key information:**
- Gene: EGFR
- Entrez Gene ID: 1956
- Chromosome: 7
- Sequence length analyzed: 9905 bp
